# 部署入门（从传统服务器到现代云原生）

> 目标：把你写好的项目，从"在我电脑上能跑"变成"全世界都能通过一个网址访问"。先看懂**传统怎么部署、为什么累**，再学会用 **CI/CD + OSS/CDN + Serverless + 云服务** 这套现代方式，不碰服务器就把前端 + 后端 + AI 的完整项目送上线。

## 这篇教程适合谁？

- 会写前端（Vue/React）、会写后端（FastAPI/Node），但项目一直只在本地跑的同学
- 想把自己的 AI 应用发布出去，让别人用网址就能访问的同学
- 听过 CI/CD、Serverless、CDN、OSS，但没有清晰画面的同学
- 想搞懂"现在的项目到底是怎么上线的"的同学

## 学完你能做到

1. 说清楚传统"自己一台服务器"的部署全流程，以及它累在哪
2. 理解现代部署"不碰服务器"的思路，以及相比传统的好处
3. 讲清 CI/CD 解决什么问题、一条流水线的主流程是什么
4. 把前端 build 后部署到 **OSS + CDN**，全国加速访问
5. 把后端打成 **Docker 镜像**，用 **Serverless** 跑起来
6. 理解为什么数据库、AI 都直接用**云端服务/API**，以及"无状态思维"
7. 配好域名与 HTTPS，把前后端拼到一个可访问的线上项目里

## 前置知识（建议先具备）

- **前端构建**：知道 `npm run build` 会产出静态文件 → [前端体系化快速进阶](../../前端体系化快速进阶/)
- **后端接口**：知道怎么写一个 HTTP 接口 → [FastAPI 入门](../../python服务端进阶/FastApi入门/)
- **Docker**：知道容器怎么打包镜像 → [Docker 入门](培训班/基础阶段/系统架构体系/docker入门/README.md)

> 没学过也没关系，本教程重在建立"部署"的全局认知，涉及到的概念都会用类比讲清楚。

## 怎么用这份教程？

- **赶时间**：看 01、02、03 搞懂"传统为什么累、现代好在哪"，再看 04 的全景图，半小时建立认知。
- **想系统学**：从头到尾按顺序读，每章都有类比和架构图，重在理解整条链路怎么串起来。

> 重要提醒：这份教程默认用**国内云**（阿里云 / 腾讯云 + 通义 / 豆包）举例，讲的是思路和链路，不同平台按钮位置不同，但道理相通。
