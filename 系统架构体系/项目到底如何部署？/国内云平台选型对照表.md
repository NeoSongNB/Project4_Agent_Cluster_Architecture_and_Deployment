# 附录 · 国内云平台选型对照表

这份对照表帮你在动手时快速选型。**没有绝对的最优，选你熟悉的一家云厂商，把它的全套服务用起来最省心**（同一账号、同一控制台、内网互通、账单统一）。价格随时变动，以官网实时为准。

## 前端托管：OSS + CDN

| 能力 | 阿里云 | 腾讯云 | 说明 |
|------|--------|--------|------|
| 对象存储 | **OSS** | **COS** | 存前端静态文件 |
| CDN | CDN / DCDN | CDN / EdgeOne | 全国就近加速 |
| 静态网站托管 | OSS 自带 | COS 自带 | 开开关、设 index.html |

> 选型建议：跟着你后端所在的云厂商走，同厂商内网回源更快、更省流量费。

## 后端：Serverless（跑 Docker 镜像）

| 类型 | 阿里云 | 腾讯云 | 特点 |
|------|--------|--------|------|
| 函数计算 (FaaS) | **函数计算 FC**（支持容器镜像） | **云函数 SCF**（支持镜像） | 按请求计费、缩容到零，轻量 |
| Serverless 容器 | **SAE**（Serverless 应用引擎） | **云托管 CloudBase Run** | 直接跑容器、更像常规后端服务 |

> 选型建议：用 FastAPI + Docker 的常驻 HTTP 服务，**Serverless 容器**这类通常更顺手；追求极致省钱、事件驱动的轻量场景可选函数计算。

## 镜像仓库

| 阿里云 | 腾讯云 |
|--------|--------|
| 容器镜像服务 **ACR** | 容器镜像服务 **TCR** |

> 用于存 CI/CD 构建出的后端镜像，供 Serverless 拉取。选和后端同厂商的。

## 数据库：云托管

| 类型 | 阿里云 | 腾讯云 |
|------|--------|--------|
| 关系型（MySQL/PG） | **RDS**、PolarDB | **云数据库 MySQL / PostgreSQL** |
| Serverless 数据库 | PolarDB Serverless | TDSQL-C Serverless |
| 缓存 (Redis) | 云数据库 Redis (Tair) | 云数据库 Redis |

> 选型建议：起步用最小规格 RDS 即可；想连数据库也按量伸缩，选 Serverless 数据库。

## AI 能力：云端 API

| 提供方 | 产品 | 备注 |
|--------|------|------|
| 阿里 | **通义千问**（DashScope 百炼平台） | 模型全、生态好 |
| 字节 | **豆包**（火山方舟） | 性价比高 |
| 智谱 | GLM 系列 | |
| 月之暗面 | Kimi | 长上下文 |
| DeepSeek | DeepSeek 系列 | 性价比高 |

> 大多兼容 OpenAI 调用格式，切换成本低。选型看**模型效果 + 价格 + 是否兼容 OpenAI SDK**。

## CI/CD 平台

| 平台 | 说明 |
|------|------|
| **GitHub Actions** | 通用、生态好，本教程示例用它 |
| **GitLab CI** | 自建 GitLab 常用 |
| 云效 (阿里云) / CODING (腾讯云) | 国内云厂商自带，和其云服务集成更顺 |

> 选型建议：代码在 GitHub 用 Actions；代码在国内平台或想和云服务深度集成，用云效/CODING。

## 域名与备案

| 能力 | 阿里云 | 腾讯云 |
|------|--------|--------|
| 域名注册 | 万网 / 阿里云域名 | 腾讯云域名 |
| DNS 解析 | 云解析 DNS | DNSPod |
| 备案 | 阿里云备案系统 | 腾讯云备案系统 |
| SSL 证书 | 数字证书服务（有免费） | SSL 证书服务（有免费） |

> 提示：域名、备案、证书尽量和你用的云厂商放一起，流程最顺。**备案尽早办。**

## 一句话选型总结

> **先定一家主云厂商（阿里云或腾讯云），把 OSS+CDN、Serverless、镜像仓库、云数据库、域名/备案/证书全用它的；AI 按效果和价格单独选；CI/CD 用 GitHub Actions 或云厂商自带。** 全家桶用法最省心。
