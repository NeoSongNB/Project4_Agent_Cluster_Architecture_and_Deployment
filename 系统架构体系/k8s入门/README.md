# Kubernetes（K8s）极速入门（面向 AI 应用开发）

> 目标：1 小时内，让你彻底搞懂 K8s 是干嘛的、有哪些核心概念、实际工作中怎么用云上的 K8s。**不深入细节，重在建立全局认知。**

## 这篇教程适合谁？

- 已经学完 [Docker 入门](培训班/基础阶段/系统架构体系/docker入门/README.md)，想知道"容器多了之后怎么管"的同学
- 经常听别人聊 K8s、Pod、Deployment，但一头雾水的同学
- 想搞清楚"我这个 AI 项目到底该不该上 K8s"的同学

## 学完你能做到

1. 用一句话解释清楚 K8s 是干嘛的、解决什么问题
2. 听懂别人聊 Pod、Deployment、Service、Ingress 是在说什么
3. 理解 K8s 最核心的思想——声明式
4. 知道生产上大家其实都用云厂商的托管 K8s，以及大致怎么用
5. 做出判断：你的项目现阶段到底该不该上 K8s

## 前置知识

- 你需要先搞懂 Docker（镜像、容器是什么）。如果还没学，先看 → [Docker 入门](培训班/基础阶段/系统架构体系/docker入门/README.md)

## 怎么用这份教程？

- **赶时间**：看 01、02 搞懂"为什么"，再扫一遍 04 的核心概念，20 分钟建立认知。
- **想系统学**：从头到尾按顺序读，每章都有生活类比，不用记命令，重在理解。

> 重要提醒：这份教程的目的**不是**让你成为 K8s 运维专家，而是让你**看懂、听懂、会判断**。真正动手运维 K8s 是另一个更深的话题。
