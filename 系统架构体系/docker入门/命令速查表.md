# Docker 命令速查表

> 打印出来贴墙上，或收藏随时查。覆盖日常 90% 的使用场景。

## 镜像 Image

| 命令 | 作用 |
|------|------|
| `docker pull <镜像>` | 从仓库下载镜像 |
| `docker images` | 查看本地镜像列表 |
| `docker rmi <镜像>` | 删除本地镜像 |
| `docker build -t <名字> .` | 用当前目录 Dockerfile 构建镜像 |
| `docker tag <镜像> <新标签>` | 给镜像打标签（push 前用） |

## 容器 Container

| 命令 | 作用 |
|------|------|
| `docker run <镜像>` | 用镜像启动容器 |
| `docker ps` | 查看正在运行的容器 |
| `docker ps -a` | 查看所有容器（含已停止） |
| `docker stop <容器>` | 停止容器 |
| `docker start <容器>` | 启动已停止的容器 |
| `docker restart <容器>` | 重启容器 |
| `docker rm <容器>` | 删除容器 |
| `docker rm -f <容器>` | 强制删除（运行中也能删） |
| `docker logs <容器>` | 查看日志 |
| `docker logs -f <容器>` | 实时跟踪日志 |
| `docker exec -it <容器> bash` | 进入运行中的容器 |

## docker run 常用参数

| 参数 | 作用 |
|------|------|
| `-d` | 后台运行 |
| `-p 主机端口:容器端口` | 端口映射（外部访问的关键） |
| `--name 名字` | 给容器命名 |
| `-v 主机目录:容器目录` | 挂载数据卷（放模型/数据） |
| `-e KEY=value` | 设置环境变量（放 API Key） |
| `--rm` | 容器停止后自动删除 |
| `--gpus all` | 使用 GPU |
| `-it` | 交互式终端 |

## 镜像分享

| 命令 | 作用 |
|------|------|
| `docker login` | 登录 Docker Hub |
| `docker push <用户名>/<镜像>:<标签>` | 上传镜像到仓库 |
| `docker save -o app.tar <镜像>` | 把镜像导出成文件 |
| `docker load -i app.tar` | 从文件导入镜像 |

## 清理（释放磁盘）

| 命令 | 作用 |
|------|------|
| `docker system df` | 查看 Docker 占用的磁盘空间 |
| `docker container prune` | 删除所有已停止的容器 |
| `docker image prune` | 删除悬空（无用）镜像 |
| `docker system prune` | 清理所有无用资源（谨慎用） |

## Dockerfile 常用指令

| 指令 | 作用 |
|------|------|
| `FROM` | 指定基础镜像 |
| `WORKDIR` | 设置工作目录 |
| `COPY` | 复制文件到镜像 |
| `RUN` | 构建时执行命令（如装依赖） |
| `EXPOSE` | 声明端口（说明用途） |
| `ENV` | 设置环境变量 |
| `CMD` | 容器启动时执行的命令 |

## docker-compose

| 命令 | 作用 |
|------|------|
| `docker compose up -d` | 启动所有服务（后台） |
| `docker compose down` | 停止并清理所有服务 |
| `docker compose logs -f` | 查看所有服务日志 |
| `docker compose ps` | 查看服务状态 |

## 最常用的一套组合拳

```bash
docker build -t my-ai-app .                          # 构建
docker run -d -p 8000:8000 --name ai my-ai-app       # 运行
docker ps                                            # 确认在跑
docker logs ai                                       # 排错
docker stop ai && docker rm ai                       # 停止并删除
```
