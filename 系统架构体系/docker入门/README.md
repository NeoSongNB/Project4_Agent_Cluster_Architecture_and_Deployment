# Docker 极速入门（面向 AI 应用开发）

> 目标：1-2 小时内，让你彻底搞懂 Docker 是什么，并能亲手把一个 FastAPI 服务装进 Docker 跑起来。

## 这篇教程适合谁？

- 正在学 AI 应用开发，但被"环境配置"折磨过的同学
- 想把自己的 AI 服务部署到服务器、分享给别人的同学
- 听说过 Docker，但一直没搞懂它到底是干嘛的同学

## 学完你能做到

1. 用一句话向别人解释清楚 Docker 是什么
2. 看懂并写出一个 `Dockerfile`
3. 把一个 FastAPI 写的 AI 服务打包成镜像，一条命令跑起来
4. 换台电脑、给同学，也能一键运行（体会"在我电脑上能跑"问题被彻底解决）
